## There is nothing left that a session in this repository can close

v2.17 said a version would close nothing; v2.18 closed the last process finding and confirmed it. The five above are the complete list, and none of them can be moved by editing files:

- **1 and 2** need a device. `usable_encoder()` will report it the moment one exists.
- **3** needs an API key and a budget. The seam, the two passes, both judges and the gate are built and tested.
- **4** needs a contract. `tests/corpus.py` is the specification of what to buy.
- **5** needs a person who is not the author of the rubric. The harness to compare their labels exists.

## v2.19 is the GPU hour, not a review cycle

`COMPLETION-PLAN.md` sets out the remaining work as seven steps with ranges. Step 1 is one session on a rented GPU and it closes two findings and fills §12's matrix with measured numbers instead of targets.

A v2.19 that was another review cycle would be the sixth consecutive version whose content is the project describing itself. The audit measures that as padding and the plan replaces it with a sequence.

## If a version must be cut without hardware

The only defensible content is a **deletion pass**: the specification is 2,770 lines for roughly 5,000 lines of Python, and the ratio has never been examined. Sections the implementation has proved unnecessary could go, and it would be the first version since v2.3 whose main change was a removal.

That is worth doing eventually. It is not worth doing before a GPU has run the matrix, because deleting a section the hardware has not exercised is guessing dressed as rigour.
