## 6 — The labelled set contains no plan the shape judge alone can catch

**Severity: low, and v2.16 created it.**

The coverage measurement showed the shape judge adds nothing: every plan it catches, the threshold judge catches too. That is because the labelled set is built from realistic failures — hooks too long, totals wrong, cuts too few — and the product's own bounded hook makes an evenly divided plan fail a threshold as well.

A set that contained a plan with a *short* hook, the right total, enough cuts, and perfectly even lengths would be caught by the shape judge alone. It is constructible: a hook of 90 frames followed by four shots of 315 would be even in the middle. Whether such a plan is *bad* is a judgement nobody has made, which is exactly why it is not in the set.

**Proposed resolution.** Decide whether a film that hits every threshold but divides its body evenly is a bad film. If yes, add it to the set and the shape judge earns its place; if no, delete the shape judge and say the second opinion was measured and retired.
